================================================================================
                  NEXTJS TEMPLATE APP - WINDOWS SETUP GUIDE
================================================================================

This guide contains all environment parameters and commands needed for Windows
development setup.

================================================================================
                         ENVIRONMENT VARIABLES (.env)
================================================================================

Create a file named .env in the root directory with the following variables:

# Database Configuration
DATABASE_URL="mysql://username:password@localhost:3306/next_template_db"
# Replace username, password, and database name with your MySQL credentials
# Example: DATABASE_URL="mysql://root:mypassword@localhost:3306/next_template_db"

# NextAuth Configuration (REQUIRED)
NEXTAUTH_SECRET="your-secret-key-here-change-this-in-production"
# Generate a secure secret using PowerShell:
# [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes([System.Guid]::NewGuid().ToString() + [System.Guid]::NewGuid().ToString()))
NEXTAUTH_URL="http://localhost:3000"

# Email Configuration (SMTP)
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="587"
SMTP_SECURE="false"
SMTP_USER="your-email@gmail.com"
SMTP_PASS="your-app-password"
# For Gmail: Enable 2FA and generate an App Password
FROM_EMAIL="your-email@gmail.com"

# App Settings
APP_NAME="NextJS Template App"
APP_URL="http://localhost:3000"

# Feature Flags (Optional)
ENABLE_WORKFLOWS="true"

================================================================================
                         PREREQUISITES INSTALLATION
================================================================================

1. Install Node.js (18.17 or later):
   - Download from: https://nodejs.org/
   - Run installer and follow prompts
   - Verify installation:
     node --version
     npm --version

2. Install MySQL:
   - Download from: https://dev.mysql.com/downloads/mysql/
   - Run installer (mysql-installer-web-community-8.0.x.msi)
   - Choose "Developer Default" setup type
   - Complete installation with default options
   - Set MySQL root password (remember it!)
   - Verify installation:
     mysql --version

3. Install Git (if not installed):
   - Download from: https://git-scm.com/download/win
   - Run installer with default options
   - Verify installation:
     git --version

4. Install VS Code (Recommended):
   - Download from: https://code.visualstudio.com/
   - Install recommended extensions:
     - Prisma
     - ESLint
     - Prettier
     - Tailwind CSS IntelliSense

5. Verify all installations:
   node --version    # Should be 18.17.0 or higher
   npm --version    # Should be 9.0.0 or higher
   mysql --version  # Should show MySQL 8.0 or higher
   git --version    # Should show Git 2.30 or higher

================================================================================
                         INITIAL SETUP COMMANDS
================================================================================

# Open PowerShell or Command Prompt as Administrator

# 1. Navigate to project directory
cd C:\path\to\nextjs-template

# 2. Clone the repository (if not already cloned)
git clone <repository-url> nextjs-template
cd nextjs-template

# 3. Install dependencies
npm install

# 4. Create .env file from template
copy .env.example .env
# Or in PowerShell:
Copy-Item .env.example .env

# 5. Edit .env file with your settings
notepad .env
# Or use VS Code:
code .env

# 6. Generate Prisma Client
npm run db:generate

# 7. Start MySQL service (if not running)
# Open Services (services.msc) or use PowerShell:
Start-Service -Name "MySQL80"
# Or:
net start MySQL80

# 8. Create MySQL database
mysql -u root -p
# In MySQL prompt:
CREATE DATABASE next_template_db;
EXIT;

# 9. Run database migrations
npm run db:migrate

# 10. Seed the database with sample data
npm run db:seed

================================================================================
                         MYSQL COMMANDS (WINDOWS)
================================================================================

# Start MySQL service (PowerShell as Administrator)
Start-Service -Name "MySQL80"
# Or Command Prompt:
net start MySQL80

# Stop MySQL service
Stop-Service -Name "MySQL80"
# Or:
net stop MySQL80

# Restart MySQL service
Restart-Service -Name "MySQL80"
# Or:
net stop MySQL80
net start MySQL80

# Check MySQL service status
Get-Service -Name "MySQL80"
# Or:
sc query MySQL80

# Connect to MySQL
mysql -u root -p
# Or with specific database:
mysql -u root -p next_template_db

# Create database manually
mysql -u root -p -e "CREATE DATABASE next_template_db;"

# Drop database (WARNING: deletes all data)
mysql -u root -p -e "DROP DATABASE next_template_db;"

# Import SQL file
mysql -u root -p next_template_db < file.sql

# Export database
mysqldump -u root -p next_template_db > backup.sql

# Find MySQL installation path
Get-Service -Name "MySQL80" | Select-Object -ExpandProperty DisplayName

================================================================================
                         COMMON WINDOWS ISSUES & SOLUTIONS
================================================================================

Issue: "MySQL80 service not found"
Solution:
  1. Check if MySQL is installed: mysql --version
  2. Check services: Get-Service | Where-Object {$_.Name -like "*mysql*"}
  3. Reinstall MySQL if needed

Issue: "Port 3000 already in use"
Solution:
  PowerShell: Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess | Stop-Process
  Command Prompt: netstat -ano | findstr :3000 (then kill PID)

Issue: "Permission denied" errors
Solution:
  - Right-click PowerShell/Command Prompt
  - Select "Run as Administrator"
  - Try command again

Issue: "Cannot connect to MySQL"
Solution:
  1. Check if MySQL service is running: Get-Service MySQL80
  2. Start service: Start-Service MySQL80
  3. Check firewall settings
  4. Verify credentials in .env file

Issue: "npm install fails"
Solution:
  1. Clear cache: npm cache clean --force
  2. Delete node_modules and package-lock.json
  3. Run: npm install
  4. Check internet connection

Issue: "Prisma generate fails"
Solution:
  1. Check DATABASE_URL in .env is correct
  2. Ensure MySQL is running
  3. Try: npx prisma generate
  4. Check prisma/schema.prisma syntax
